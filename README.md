# 赛鸽血统环号登记站

两棚并册用的旧数据迁移与归并系统。

运行：

```bash
npm start
```

访问`http://localhost:3024`。

## 功能

- **档案与血统**：鸽只档案、血统查询、转让和归巢成绩记录。
- **并册迁移**：提交另一鸽棚的旧档案 JSON，自动归并到同一足环的正式档案。
  - 同一足环只留一份正式血统档案；换过环（`previousRing`）的鸽子自动关联到旧环档案。
  - 资料不一致（鸽主、羽色、棚号、父母环号）或家谱成环时先列冲突，**不覆盖已确认记录**，需手动选择保留目标或采用来源。
  - 迁移按检查点（`submitted → analyzed → resolved → applied`）落盘，失败后从检查点重试。
  - 重复提交不新增疫苗、转让和成绩（按内容去重 + 已应用环号跳过）。
- **参赛凭据**：签发时快照血统与成绩；并册后血统或成绩变动会使已发凭据失效，读取时按当前档案重算。

## 代码结构

迁移规则、档案存储与页面入口分离：

| 文件 | 职责 |
| --- | --- |
| `src/migrate.js` | 迁移规则（纯函数）：归并分析、冲突检测、家谱成环检测、应用与检查点 |
| `src/store.js` | 档案存储：鸽只、迁移、凭据的 JSON 原子读写 |
| `src/credentials.js` | 参赛凭据：签发、失效、重算 |
| `src/pedigree.js` | 血统图谱辅助：子代/祖先遍历 |
| `src/page.js` | 页面入口：单页 HTML |
| `server.js` | HTTP 路由入口：调用上述模块 |
